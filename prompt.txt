 # Role & Context                                                                                                                                                                                                 
    You are an expert Laravel and Stripe developer. We are building a custom billing and checkout system for an existing Laravel application. We have already completed the planning phase, installed the            
  `stripe/stripe-php` package, and updated the `.env` and Enums for permissions.                                                                                                                                     
                                                                                                                                                                                                                     
    Your task is to implement the remaining phases of the project according to the implementation plan.                                                                                                              
                                                                                                                                                                                                                     
    # Requirements                                                                                                                                                                                                   
                                                                                                                                                                                                                     
    ## Phase 1: Stripe Service Foundation                                                                                                                                                                            
    1. Update `config/services.php` to include the `stripe` configuration block (key, secret, webhook_secret).                                                                                                       
    2. Create `app/Services/StripeService.php` to act as a centralized wrapper around the Stripe API. It must include methods to:                                                                                    
       - Create a Stripe Customer (using email and name).                                                                                                                                                            
       - Create a Stripe Product and Price (for dynamic amounts and addons).                                                                                                                                         
       - Create a PaymentIntent (for one-time charges).                                                                                                                                                              
       - Create a Subscription (min 12 months logic enforced).                                                                                                                                                       
                                                                                                                                                                                                                     
    ## Phase 2: Charge Customer Modal                                                                                                                                                                                
    1. Create a Livewire component `App\Livewire\Teams\Tickets\ChargeCustomerModal`.                                                                                                                                 
       - It should take a `Ticket` model as a parameter.                                                                                                                                                             
       - It must allow the user to input a custom base amount.                                                                                                                                                       
       - It must allow the user to select from a list of addons (e.g., Website Maintenance - $99/mo, SEO Optimization - $149/mo, etc.).                                                                              
       - It must include a toggle for One-Time vs. Monthly Subscription.                                                                                                                                             
       - Upon submission, it should use `StripeService` to create the Stripe Customer/Product, generate local `Invoice` and `InvoiceItem` records, generate a unique `checkout_token`, and trigger an email to the   
  customer.                                                                                                                                                                                                          
    2. Create the corresponding view `resources/views/livewire/teams/tickets/charge-customer-modal.blade.php`.                                                                                                       
       - The UI should be a beautiful modal using Tailwind CSS.                                                                                                                                                      
       - Addon cards must display an `indigo-500` outline when selected and an `indigo-600` outline on hover.                                                                                                        
    3. Modify `resources/views/livewire/teams/tickets/show.blade.php` to include a "Charge Customer" button in the sidebar (visible only if the ticket is resolved and the user has the `ChargeCustomer` permission),
  which triggers the modal.                                                                                                                                                                                          
                                                                                                                                                                                                                     
    ## Phase 3: Invoice & Email                                                                                                                                                                                      
    1. Create a Mailable `App\Mail\InvoiceCheckoutMail` that accepts the generated `Invoice` and generates a secure checkout link (`/checkout/{token}`).                                                             
    2. Create the email view `resources/views/emails/invoice-checkout.blade.php` with a clean, professional design containing the checkout button.                                                                   
                                                                                                                                                                                                                     
    ## Phase 4: Custom Checkout Page                                                                                                                                                                                 
    1. Create a Livewire component `App\Livewire\Checkout\StripeCheckout` that loads an invoice by its `checkout_token`.                                                                                             
    2. Create `resources/views/livewire/checkout/stripe-checkout.blade.php`.                                                                                                                                         
       - Must NOT use Stripe Hosted Checkout. Use Stripe Elements.                                                                                                                                                   
       - Implement an interactive 3D credit card visual that updates in real-time as the user types their Name, Card Number, and Expiry.                                                                             
       - The card must flip to the back when the user focuses on the CVV field.                                                                                                                                      
    3. Create `resources/js/checkout.js` and `resources/css/checkout.css` to handle the Stripe Elements instantiation and 3D flip animations. Update `vite.config.js` to compile these assets.                       
    4. Add the `GET /checkout/{token}` route to `routes/web.php`.                                                                                                                                                    
                                                                                                                                                                                                                     
    ## Phase 5: Webhook Handling                                                                                                                                                                                     
    1. Create `App\Http\Controllers\StripeWebhookController` to securely receive Stripe events (`payment_intent.succeeded`, `invoice.payment_succeeded`, etc.).                                                      
    2. Update the local `Transaction` and `Invoice` statuses based on the webhook payloads.                                                                                                                          
    3. Add the POST route for the webhook in `routes/web.php`, excluding it from CSRF verification.                                                                                                                  
                                                                                                                                                                                                                     
    # Technical Constraints                                                                                                                                                                                          
    - Use PHP 8.3 / Laravel 11 conventions.                                                                                                                                                                          
    - Do NOT use Laravel Cashier, as we are billing external customers without user accounts. Rely strictly on `stripe/stripe-php`.                                                                                  
    - Ensure all logic is type-hinted and secure.
